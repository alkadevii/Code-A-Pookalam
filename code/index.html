🌼 Onam Pookalam Project

Follow the steps below to create, upload and host your Onam Pookalam project using Git and GitHub.

1. Create the Project

Create a folder for your Pookalam project and add your HTML, CSS and JavaScript files.

2. Fork the Repository

Open the original GitHub repository and click Fork to create your own copy.

3. Initialize Git Repository

git init

4. Add Remote Repository

git remote add origin https://github.com/USERNAME/REPOSITORY.git

5. Add Files

git add .

6. Commit Changes

git commit -m "Add Onam Pookalam project"

7. Push to GitHub

git branch -M main
git push -u origin main

8. Host the Website

Go to your GitHub repository and open: 

Settings → Pages → Deploy from a branch

Select the main branch and click Save. GitHub Pages will host your website.
